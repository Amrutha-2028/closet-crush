# Closet Crush

A preppy, girly outfit maker. Add photos of your clothes, set today's weather and where you're going, and it styles flat-lay outfits around winter 2026 trends.

- Photos are cleaned up in the browser: auto-levels, background cut-out into die-cut stickers, or a scrapbook polaroid when the background is too busy.
- Swipe through your closet (right to keep, left to remove, with undo), or use the grid.
- Everything is stored in your own browser. Nothing is uploaded.

Open index.html in any browser, or visit the GitHub Pages site.
